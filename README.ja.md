# EbookLosslessDownloader

[English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md)

**EbookLosslessDownloader（電子書籍ロスレスダウンローダー）** は、対応プラットフォームからアクセス可能な電子書籍ページをダウンロードし、可能な限り元の画質を維持しながら、形式変換、OCR、ZIP / CBZ / PDF / EPUB への出力に対応するユーザースクリプトです。

- English: EbookLosslessDownloader
- 中文：电子书无损下载器

## ここでいう「lossless / ロスレス」とは

ここでの「lossless」は、プラットフォームがリーダーに提供したページデータに対して、**不要な追加劣化を可能な限り発生させない**ことを意味します。すべての元ページがオリジナルの可逆マスター画像である、という意味ではありません。

条件を満たす JPG ページでは、EbookLosslessDownloader は量子化済み JPG DCT 係数を直接並べ替え、画像を逆量子化・再量子化することなくエントロピーストリームを再エンコードできます。これにより、新たな JPG 世代による追加の不可逆劣化を回避します。ただし、元の JPG 自体には出版社やプラットフォームによる圧縮劣化がすでに含まれている場合があります。

PNG、lossless WEBP、lossless JXL への出力では、変換経路で得られたデコード済みピクセルデータを可逆的に保持します。すでに不可逆圧縮された JPG を可逆形式へ変換しても、元の JPG に存在しない情報が復元されるわけではありません。

## 機能

- [x] 可能な限り元のページデータを保持し、不要なデコード / 再エンコードを回避。
- [x] 条件を満たす JPG ページに対する係数領域での復元。NFBR ブロック並べ替えを DCT 領域で直接実行できる場合、追加の JPG 量子化劣化を回避。
- [x] 画像出力：**JPG、JXL、PNG、WEBP**。
- [x] パッケージ出力：**ZIP**。
- [x] ⚠️ **実験的 / 未検証：** **CBZ、PDF、EPUB** へのパッケージ出力。PDF では JPG ページ画像を使用し、分割出力に対応し、OCR テキストをテキストレイヤーとして埋め込めます。
- [x] ⚠️ **実験的 / 未検証：** 検出されたテキストページを **4 色 PNG** に自動変換。
- [x] ⚠️ **実験的 / 未検証：** **日本語 + 英語** 認識による OCR。
- [x] ZIP / CBZ / EPUB のストリーミング書き込みにより、アーカイブ生成時のメモリ使用量を削減。
- [x] 利用可能な場合は OPFS を一時保存に使用し、IndexedDB / メモリへフォールバック。異常終了後に残った古い OPFS データも自動的にクリーンアップ。
- [x] 画像コーデックおよび JPG 係数処理を Web Worker で実行。
- [x] 小規模な OCR Worker プールにより、認識処理とページ処理を並行化。
- [x] Material Design 3 UI。
- [x] UI 言語：**中文 / English / 日本語**。選択した言語はローカルに保存。
- [x] 診断情報や保存品質 / 処理時間メタデータを扱う隠し開発者モード。

## インストールと使い方

1. Tampermonkey または Violentmonkey などのユーザースクリプトマネージャーをインストールします。
2. 下記の Raw ユーザースクリプト URL から `EbookLosslessDownloader.user.js` をインストールします。この URL からインストールすると、ユーザースクリプトマネージャーがインストール元を記録し、スクリプトで設定された更新 URL を利用できます。

   ```text
   https://raw.githubusercontent.com/Li3Zi3han2/EbookLosslessDownloader/main/EbookLosslessDownloader.user.js
   ```

3. 対応する試し読み / プレビュー、または購入済み電子書籍を Web リーダーで開きます。EbookLosslessDownloader パネルが自動的に表示されます。
4. 表示言語を変更するには、最小化ボタンのすぐ左にある翻訳風ボタンから **中文**、**English**、**日本語** のいずれかを選択します。選択内容はローカルに保存されます。
5. パネルに総ページ数と **就绪 / Ready / 準備完了** が表示されるまで待ちます。
6. ページ範囲、出力サイズ、画像形式、品質設定を選択します。
7. 必要に応じて 4 色テキストページ変換、OCR、分割出力を有効にします。
8. ZIP、CBZ、PDF、EPUB のいずれかを選択して、ダウンロードを開始します。
9. 開発者モードを有効にするには、バージョン番号を素早く 5 回クリックします。開発者モードでは追加の診断出力、詳細な処理時間情報、および対応するアーカイブ形式への `manifest.json` 保存品質メタデータが追加されます。有効時にバージョン番号を 1 回クリックすると無効化できます。

## 出力形式

### 画像

| 形式 | 説明 |
| --- | --- |
| JPG | ファイルサイズを抑えたい場合。条件を満たすと DCT 領域での保存処理を使用。 |
| JXL | 高効率な現代的な不可逆 / 可逆画像出力。 |
| PNG | 可逆出力。⚠️ **実験的 / 未検証：** 検出されたテキストページに対する 4 色最適化を選択可能。 |
| WEBP | 不可逆または可逆画像出力。 |

### パッケージ

| 形式 | 説明 |
| --- | --- |
| ZIP | 画像アーカイブ。画像に対して無意味な ZIP 再圧縮は行いません。 |
| CBZ | ⚠️ **実験的 / 未検証。** `ComicInfo.xml` を含むコミック用 ZIP。 |
| PDF | ⚠️ **実験的 / 未検証。** ページ画像は JPG に固定。OCR テキストをテキストレイヤーとして埋め込み可能。 |
| EPUB | ⚠️ **実験的 / 未検証。** 画像ベースの固定レイアウト EPUB。 |

すべてのパッケージ形式で任意の分割出力に対応します。

## ストレージとネットワーク

ページデータはブラウザ内でローカル処理されます。一時的なページ / アーカイブ保存にはブラウザの Origin Private File System（OPFS）を優先し、利用できない場合は IndexedDB またはメモリへフォールバックします。正常完了時には一時セッションデータを削除し、異常終了によって残った古いセッション / アーカイブデータは以後の実行時に自動的にクリーンアップします。

スクリプトは以下にもアクセスします：

- 現在のリーダーセッションでアクセス可能なページデータを取得するための対応電子書籍プラットフォーム；
- 実行時コーデック / ライブラリに必要なバージョン固定済み CDN リソース；
- OCR を有効にした場合の OCR 言語 / ランタイムリソース。

実行時ライブラリは特定バージョンに固定され、ローダー側で実装されているものについては期待される SHA-256 ハッシュも検証されます。
